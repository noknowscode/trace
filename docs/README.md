# TRACE Uno Platform product package

This is a self-contained handoff package for building TRACE as a .NET Uno Platform application.

Start with `PROJECT-BRIEF.md`, then follow the source-of-truth order defined there.

`prototype.html` is a runnable interaction reference. It is intentionally not the architecture to copy.

Package contents:

- PRODUCT-SPEC.md
- UNO-BUILD-SPEC.md
- COMPLETION-CHECKLIST.md
- DESIGN-GRAPH.md
- PROTOTYPE-VERIFICATION.md
- BUILD-PROMPT.md
- prototype.html
