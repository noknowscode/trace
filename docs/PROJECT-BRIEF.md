# TRACE — Project Brief

## Project type
Product-quality Uno Platform sample / reference application.

## Industry
Field operations / industrial maintenance

## Product purpose
Technician-first spatial inspection, evidence and corrective action

## Delivery objective
Rebuild the included functional HTML prototype as a real .NET Uno Platform application without reducing its product surface area. The prototype is behavioral and visual reference material, not the production architecture.

## Required deliverables
- Complete Uno Platform solution.
- Primary targets: Android + Windows.
- Every Must Have workflow implemented end-to-end.
- Durable local state and realistic seed data.
- Platform integrations behind interfaces.
- Automated coverage for critical domain rules and workflows.
- Updated design graph representing the final implementation.
- Final verification against the app-specific checklist on running targets.

## Source-of-truth order
1. PRODUCT-SPEC.md
2. UNO-BUILD-SPEC.md
3. COMPLETION-CHECKLIST.md
4. DESIGN-GRAPH.md
5. prototype.html
6. PROTOTYPE-VERIFICATION.md

If the prototype conflicts with written requirements, the written requirements win.

## Success criterion
A developer unfamiliar with the concept can build the app without inventing its core product, scope, architecture, workflow, state model, data model, visual intent or definition of done.
